### 核查 Emerald Bay 的说法(对上游数据的新计算,来源
`external/Rhaister/results_sensitivity.jsonl`,官方发布的每 split R²)

先更正一点:Emerald Bay 用的是 **few-shot Rhaister**(每个 query 系有 6 个 panel
药物),不是 Rhaister-O。任务是标量 sensitivity(log2 细胞比例),5 个 split,每个
split 5 个 query 系、n_test = 165。

| split | Rhaister | + tx features | 差 |
|---|---|---|---|
| 0 | 0.362 | 0.354 | −0.008 |
| 1 | 0.134 | 0.203 | +0.069 |
| 2 | 0.192 | 0.300 | +0.108 |
| 3 | 0.302 | 0.313 | +0.011 |
| 4 | 0.293 | 0.385 | +0.092 |
| mean ± SD | 0.257 ± 0.092 | 0.311 ± 0.069 | **+0.054 ± 0.051** |

- 用户说得对,**按论文图中的 ±1 SD 看两条区间重叠**。
- 但这是**配对**设计:5 个 split 里 4 个为正,配对 t ≈ 2.40,df = 4,双侧
  p ≈ 0.07。结论应该写成**"n = 5 个 split 下没有解析出来"**,不能写成"没有效果"。
  拿这一点去"否定"对方站不住。
- 另一个更有用的数字:半样本 A-vs-B 参照 R² = **0.987**,而 Rhaister 只有 0.26。
  Emerald Bay 的测量天花板很高、模型离天花板很远,这和 Tahoe zero-shot
  (已接近噪声地板)正好相反。

### 讨论意见(Claude,供用户和 advisor 决定)

1. **纯反驳论文不建议。**Rhaister 是 bioRxiv 预印本(2026-06);Emerald Bay 的
   特征提升只是它的次要结论,并且配对后 p ≈ 0.07,是"证据不足"而不是"错了"。
   RECOMB 是方法会议,纯否定一篇预印本的一个次要点贡献太薄。
2. **"更好的模型"这条路被我们自己的数据封住了**(本规模下):249519 加自由度、
   272027 均匀收缩、274091 化学收缩,三个方向都在 +0.002 以内;DepMap gate
   失败;cell-line 表征 0.029–0.093。5 周内再押一个模型,成功概率低。
3. **建议的论文:把已有证据组织成一篇"分辨率/测量"论文,并带一个建设性方法。**
   - 论点:在约 45 个参考语境下,严格 zero-shot benchmark 分辨不出小于其数据质量
     噪声地板的模型差异(第 6–8 节证据齐全)。
   - 建设性方法:**按参考系可靠性(DMSO 自身 plate 重复性,仅用参考系信息)做
     选择或加权**,用嵌套验证选阈值。272021 显示最好的 40 条比全部 45 条高
     +0.0142,是任何模型效应的 7 倍以上。需要一次嵌套验证实验证明它不是事后选择。
   - 通用工具:给定语境数和重复噪声,计算最小可检测效应(power 分析),并以
     Rhaister 的两个结论作为案例(Emerald Bay 的特征提升未被解析;L1000 上估计量
     输给 drug mean)。这样"反驳"是论文的一个例子,而不是论文本身。
4. **"更多数据"**:5 周内没有湿实验。最有价值的公开候选是 **Emerald Bay 自身的
   单细胞转录组**(52 系、约 180 万细胞、5 天处理、同一 Mosaic 平台),可能是
   L1000 限制中提到的"第二个背景数可比的外部图谱"。可行性(是否公开表达矩阵、
   与 Tahoe 的细胞系重叠、24 h 对 5 d)**未核实**,核实前不纳入计划。

### E1 细胞语境斜率族 `scripts/run_context_slopes.py`(回应用户:γ 与细胞系无关是可改进点)

| 臂 | 形式 | 锚点 |
|---|---|---|
| `kernel` | μ、γ 用参考系的核权重 w=exp(−d/h·) 估计,d 为中心化 DMSO 谱的相关距离,h 以参考系间距离中位数为单位 | h = ∞ |
| `varying_coef` | γ(t,g,c) = γ0(t,g) + Σ_k u_ck G_k(t,g),u 为参考系 DMSO 的前 K 个 PC(单位方差),交互项 ridge λ | λ = ∞ |
| `quadratic` | 加 γ2(t,g)·(z² − mean z²),ridge λ | λ = ∞ |
| `kg_neighbor` | 加 η(t,g)·z̄_N(g),N(g) 为 Reactome 通路邻居(通路大小 ≤ 200),ridge λ | λ = ∞ |
| `kg_random` | 同上,但邻居图为度保持的随机图——`kg_neighbor` 的阴性对照 | λ = ∞ |
| `reliability` | 参考系权重 q_c^α,q 为 DMSO 自身重复性(Tahoe 跨 plate,EB split-half) | α = 0 |

预期(写在结果之前):`kernel` 与 `varying_coef` 大概率选回锚点或接近锚点(45 条系不足以
支撑局部斜率);`kg_neighbor` 若有增益,必须显著优于 `kg_random` 才能归因于知识图谱。

### E2 unseen-drug 任务上的 drug encoder(Tahoe;EB 仅 19 个药物,不做)

整药(所有剂量)按药物 5 折留出;预测每个 (细胞系, 处理) 的 delta。模型:全局均值(各系)、
MOA 类均值、Morgan Tanimoto kNN、Morgan ridge、Morgan+MOA ridge,均加细胞系均值与剂量。
指标:full delta Pearson(细胞系平均)、药物聚类 bootstrap。
**Gate:最佳 encoder 相对 MOA 类均值的增益,药物 bootstrap 下界 > 0。**
这是与主任务不同的次要实验,单独标注。

**E5 设计修订(运行前)**:原设计(zero-shot,用 Rhaister-O 预测的转录响应作为药敏特征)有构造性

### 关键判断

1. **kernel 的增益不是"剔除坏参考系"的伪装**:核权重与 QC 无关,NCI-H596 平均权重 1.05;
   有效参考系数 30-44/45。去掉 NCI-H596 后的重跑(284937)是进一步的确认。
2. **kernel 与 reliability 机制不同,EB 上组合臂 +0.0091**(探索性)接近 +0.01。组合在 Tahoe 上的
   结果(284936)决定它是否值得作为论文的主方法。
3. **这是论文方法部分的候选**:局部加权的 Rhaister-O(query 依赖的参考系权重)+ 参考系可靠性权重。
   仍是 closed-form、秒级、可解释,但放松了"斜率与细胞系无关"的限制。用户的直觉在方向上被证实,
   效应量约 +0.013~0.02(Tahoe)。
4. **必须说的限制**:EB 未过 +0.01;6 臂 × 2 数据集同时检验,Tahoe 两个通过臂的 p 都在 50 次置换的
   下限 0.0196,未做多重比较校正;组合臂与 K 扩展是看到结果后的探索。正式结论需要一个**新的、

## 2026-10-01 00:15 — F2 结果与一个方法学发现;预注册 F3

### F2:交互特征在主指标上完全为零,但特征本身不是退化的

冒烟(split 5)结果:所有臂的内层选择都选回锚点(θ = 0;λ = 1e5~1e6 ≈ ∞),
外层增益在 1e-5 量级。**但诊断显示特征本身有真实信号**:

| 特征 | 覆盖(参考系×处理有值的比例) | 与响应**幅度** ‖Δ−drugmean‖ 的相关 |
|---|---|---|
| `target_expression` | 0.66 | **+0.075** |
| `target_dependency` | 0.51 | +0.013 |
| `target_pathway`(KG,药物→细胞轴) | 0.21 | **+0.211** |

### 为什么会这样:指标本身看不见幅度

主指标是**逐 (细胞系, 处理) 行、跨 2,000 基因的 Pearson**。Pearson 对该行的整体缩放不变,
因此任何"按 (1 + θ·x) 缩放预测"的修改在这个指标上**数学上不可见**;`direct` 形式加的是
一个固定基因方向,也几乎无效。**交互特征携带的是幅度信息,而 benchmark 的主指标是方向指标。**

这不是实现问题,是**实验设计与指标的错配**,而且它本身是一个值得写进论文的观察:
Rhaister 的 zero-shot 指标衡量"响应往哪个方向走",不衡量"这个药对这条系有多强"。
而后者恰恰是 Emerald Bay sensitivity 任务关心的量,也是治疗上更有意义的量。

### 预注册 F3:直接预测响应幅度

- **目标**:每个 (留出系 c, 处理 t) 的 drug-residual 幅度 `m(c,t) = ‖Δ(c,t) − drugmean(t)‖`,
  取 log 后**按处理在参考系内中心化**(去掉药物主效应,只留"这条系对这个药反应更强/更弱")。
- **模型**(均在参考系上拟合,ridge,λ 由参考系留一选择):
  `drug_mean`(全零,基线)、`dmso_pc`(DMSO baseline 的前 K 个 PC)、
  `target_expression`、`target_dependency`、`target_pathway`、`all_interaction`(三者并用)、
  `permuted_targets`(阴性对照)、`rhaister_magnitude`(Rhaister-O 自己预测的幅度,作为对照)。
- **指标**:每条留出系上,预测幅度与真实幅度跨处理的 Pearson;按系 bootstrap。
- **Gate**:最佳交互臂相对 `dmso_pc` 与相对 `permuted_targets` 的增益,按系 bootstrap 下界 > 0。
- 在 C1 的新 split(25 条从未评分过的系)上跑。
